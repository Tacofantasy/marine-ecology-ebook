# Redis 会话与分级管理员认证设计

## 目标与边界

本迭代将现有 Sa-Token 无状态 JWT 认证迁移为 Redis 托管会话，并完成当前认证页面所需的前端会话存储改造。范围仅覆盖认证、账号状态和管理员层级，不实现分类、电子书、章节、点赞、统计或 WebSocket。

认证接口继续使用既有的 `/api/auth/*` 路径，避免破坏已完成的前端认证调用；后续新增业务模块再按需求分析文档使用 `/category/*`、`/ebook/*`、`/doc/*` 等路径。

## 方案选择

采用 Sa-Token 默认有状态逻辑加 `sa-token-redis` 持久化登录会话。浏览器把 Sa-Token 返回的 `satoken` 凭证及公开用户资料写入 `sessionStorage`，请求仍使用 `satoken` 头。会话 TTL 为 24 小时。

该方案相对于保留 JWT 的优势是：退出登录、禁用或注销账号后可立即删除服务端会话；相对于把用户资料本身写入 Redis 的自建 Token 方案，复用 Sa-Token 的登录、校验与踢下线能力，代码和测试更少。

## 账号模型与权限

用户角色固定为 `USER`、`ADMIN`、`SUPER_ADMIN`：

- 公开注册只能创建启用的 `USER`，服务端不接受角色字段。
- `ADMIN` 可管理电子书、分类、章节和普通用户，但不能创建、禁用、注销、重置或提升任何管理员。
- `SUPER_ADMIN` 拥有 `ADMIN` 的内容管理权限，并负责子管理员管理。系统不得出现最后一名启用总管理员被禁用或注销的状态。
- 账号删除为逻辑删除：账号不可登录、常规列表不显示，历史点赞和统计记录保留。
- `username` 是唯一且不可变的登录名；`display_name` 是可编辑昵称；邮箱仅为可选联系字段。

生产环境首次启动时，若不存在总管理员，读取 `INITIAL_SUPER_ADMIN_USERNAME` 与 `INITIAL_SUPER_ADMIN_PASSWORD` 创建一个账号；已存在总管理员时不覆盖。开发环境提供明确的本地初始化配置，不将真实密码提交到仓库。

## 接口与会话流

| 接口 | 行为 |
| --- | --- |
| `POST /api/auth/register` | 创建 `USER`，返回公开用户资料。 |
| `POST /api/auth/login` | 验证密码和账号状态，创建 Redis 会话，返回 Token 与用户资料。 |
| `GET /api/auth/me` | 返回当前有效会话对应的用户资料。 |
| `POST /api/auth/logout` | 使当前 Redis 会话立即失效，返回成功。 |

登录、`/me` 与管理员鉴权均以数据库中仍启用且未注销的账号为最终依据。若账号被禁用或逻辑注销，服务端删除当前会话并返回未登录错误。前端收到未登录错误时清空 `sessionStorage` 并跳转到登录页；登录后的回跳地址只接受单个以 `/` 开始、但不以 `//` 开始的站内路径。

接口成功响应继续为 `{ code, message, data, timestamp }`。请求头仍为 `satoken`，不切换为需求文档示例中的 `token`，以保持现有接口兼容。

## 数据与配置变更

Flyway 迁移将扩展 `users`：角色允许 `SUPER_ADMIN`，增加昵称和逻辑注销信息，并将当前本地演示管理员迁移为总管理员。Redis 地址、端口与会话配置全部可由环境变量覆盖；`compose.yaml` 增加仅供本地开发的 Redis 服务和数据卷。`.env.example` 只保存占位值与变量说明。

前端仅替换认证模块的存储介质，不引入 Pinia、Vuex 或额外状态库。本迭代会把已完成的登录、注册、个人页认证流并入本分支，再将其存储方式迁移到 `sessionStorage`。

## 错误处理与验证

- 注册重复登录名、保留名称或无效输入返回既有业务错误码；密码仍使用 BCrypt，绝不使用 MD5。
- 登录失败统一返回“账号或密码错误”，不泄露账号是否存在或被禁用。
- 无有效会话返回 `40101`；普通用户访问管理员接口返回 `40301`；子管理员访问总管理员专属接口也返回 `40301`。
- 后端自动化测试覆盖：TTL、退出即时失效、禁用/注销即时失效、公开注册角色、三类角色边界和最后总管理员保护。
- 前端验证覆盖：构建成功、Token 仅存在于 `sessionStorage`、受保护请求带 `satoken`、非法回跳地址被拒绝。

## 完成标准

Docker MySQL 和 Redis 均可启动时，认证测试全部通过；浏览器可注册普通用户、登录、刷新页面后保持会话、退出后立即失效；普通用户和子管理员无法越权访问总管理员操作。所有真实密码、Token 与 Redis 数据均不写入日志、Git 或接口响应。
