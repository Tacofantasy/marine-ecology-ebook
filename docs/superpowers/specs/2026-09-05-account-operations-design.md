# 账号与管理员运营设计

## 目标

将现有仅能查询、注销账号的管理页完善为可日常运营的账号管理：总管理员可创建子管理员、启用或禁用非总管理员账号、重置其密码；子管理员只可启用或禁用普通用户。注销保留为不可恢复的逻辑删除。

## 权限与状态

- `SUPER_ADMIN`：可管理 `ADMIN` 与 `USER`，不能管理自己或任意 `SUPER_ADMIN`。
- `ADMIN`：仅可管理 `USER`，不能查看管理员账号。
- `USER`：无管理权限。
- 正常账号为 `status=1`，禁用账号为 `status=0` 且未注销，可重新启用；注销账号写入 `deleted_at`，不可恢复且不参与默认列表。

## 接口与界面

保留列表和注销接口，新增创建子管理员、更新账号状态与重置密码接口。列表支持角色和状态筛选；页面只展示当前操作者可管理的账号。总管理员获得“新增子管理员”入口；每一行根据角色与状态只显示有效操作。表单有可见标签、校验、加载和结果反馈。

## 验证

集成测试覆盖创建子管理员、状态切换、密码重置后旧会话失效、角色边界和列表隔离；前端生产构建必须通过。
