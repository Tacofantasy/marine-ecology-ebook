# 海洋生态数字电子书全站体验重构设计

## 1. 目标

在不改变后端接口、权限规则和核心业务流程的前提下，统一重构读者端与管理端前端体验。保留现有海洋蓝、青色高光、波浪形态和轻透卡片等品牌特征，解决当前首屏内容入口偏后、公共导航与管理导航混杂、页面信息层级不稳定、阅读工具分散、管理操作密度不合理等问题。

重构后的体验应让用户更快完成四项核心任务：

1. 访客快速发现并打开感兴趣的电子书。
2. 注册用户顺畅阅读、点赞、收藏和返回收藏内容。
3. 管理员清楚地完成分类、电子书、章节和账号管理。
4. 项目演示时能够在较短路径内呈现平台的内容、互动和管理能力。

## 2. 设计原则

- 内容优先：首页首先服务于“找书”，阅读页首先服务于“读正文”，管理页首先服务于“完成操作”。
- 双壳层结构：读者端采用轻量顶部导航，管理端采用固定侧边工作台导航；两者共用设计令牌与基础组件。
- 保留品牌、降低装饰负担：保留海洋氛围，但缩短大面积 Hero，减少重复平台介绍和无功能装饰。
- 渐进披露：高级操作、规则说明和危险操作只在相关上下文中出现。
- 状态明确：加载、空数据、错误、成功、筛选中和不可用状态均给出明确反馈和下一步。
- 响应式优先：在 375、768、1024 和 1440 像素宽度下保持可用，不依赖悬停完成关键操作。
- 无障碍基础：文本对比度至少 4.5:1，交互目标至少 44×44 像素，保留键盘焦点、语义标题、跳到正文和减少动态效果支持。

## 3. 信息架构

### 3.1 读者端

读者端顶部导航包含：品牌、书库、我的收藏（仅注册用户）、身份入口。管理员登录后保留“进入管理台”入口，但管理模块不再全部挤在公共导航中。

读者端页面层级：

```text
首页书库
├── 搜索与分类筛选
├── 电子书列表
└── 平台数据概览

阅读页
├── 电子书上下文
├── 章节目录
├── 章节正文
└── 点赞、收藏与章节切换

个人空间
├── 我的收藏
└── 账号资料
```

### 3.2 管理端

管理端使用独立工作台框架。桌面端左侧为品牌、模块导航和返回书库入口，右侧为页面内容；移动端侧栏收纳为抽屉。

导航模块为：内容概览、分类管理、电子书管理、用户管理、账号资料。内容概览不新增后端能力，复用现有统计接口与已有管理入口。

章节管理是电子书管理的下钻页面，通过面包屑与明确的“返回电子书管理”入口表达层级，不在一级导航中单列。

## 4. 视觉系统

### 4.1 色彩

延续海洋主题，但将颜色改为语义令牌，避免组件中散落原始色值：

- 深海色：用于品牌、管理侧栏和高强调背景。
- 海蓝色：用于主要按钮、选中导航和主要链接。
- 潮汐青：用于互动状态、数据强调和轻量装饰。
- 泡沫白：用于页面背景和浅色选中状态。
- 珊瑚红：仅用于错误、注销、删除等危险语义。
- 中性墨色：用于正文和标题，避免浅灰文字造成低对比度。

### 4.2 字体与层级

继续使用适合中文系统环境的无衬线字体栈，不引入必须联网加载的字体。正文基准为 16px、行高不低于 1.6；阅读正文为 17–18px、行高约 1.85。标题采用清楚的三级层级，避免使用字号承担全部分组职责。

### 4.3 形态与动效

卡片圆角、阴影和边框统一为少量级别。波浪只用于首页 Hero、认证页或页脚等品牌区域，不在每个管理页面重复。交互动效控制在 160–240ms，以颜色、透明度和轻微位移为主，不动画宽高；系统偏好减少动态效果时关闭非必要动画。

## 5. 页面设计

### 5.1 全局应用框架

公共顶部栏高度收紧，滚动时保持可见但不遮挡正文。当前页面使用明确的选中状态。桌面端用户入口改为头像菜单，集中放置个人资料、我的收藏或管理台、退出登录；移动端使用菜单按钮展开导航。

页脚缩短为品牌说明、核心入口和项目归属三部分。阅读页和管理端使用更轻的页脚或不显示大页脚，避免打断任务。

应用框架根据路由元信息选择公共布局、认证布局、阅读布局或管理布局。布局选择只影响呈现，不改变现有权限守卫。

### 5.2 首页书库

首页将现有近 580px 的 Hero 缩短为内容型首屏：左侧呈现标题、简短说明和搜索框，右侧使用抽象海洋视觉或数据摘要。访客与登录用户看到相同的书库主入口，登录/注册退居辅助位置。

搜索与分类合并为同一探索区域：

- 一级分类作为分组标签或导航。
- 二级分类作为可切换筛选项。
- 当前关键词与分类显示为可移除的筛选条件。
- 提供“全部内容”和清空筛选入口。
- 搜索、分类与分页继续调用现有电子书列表接口。

电子书采用响应式卡片网格。封面保持稳定比例并预留空间，卡片显示分类、标题、两行简介、发布时间、点赞数和“开始阅读”。整张卡片可进入阅读页，同时保留清晰的键盘焦点。加载时使用骨架屏，空状态根据是否存在筛选条件给出不同引导，接口失败显示区域内重试，不让整页变成错误页面。

统计信息从当前六卡片加完整折线图调整为更靠后的“平台动态”区。首页默认展示精简统计；趋势图保留但降低视觉权重，并继续支持失败重试和导出图片。现有“平台能力”三卡片删除或压缩为一行简要说明，避免与真实内容争夺注意力。

### 5.3 阅读页

阅读页采用专用沉浸布局：顶部为紧凑阅读工具栏，显示返回书库、电子书标题、目录开关和互动操作。电子书大 Hero 缩减为正文前的简要书籍信息区。

桌面端为“目录 + 正文”两栏：目录固定在可视区域内，正文列宽控制在舒适阅读范围。当前章节具有明确状态，章节数量较多时目录区域自身滚动。移动端目录进入抽屉，通过固定工具栏打开。

正文保留富文本能力，统一图片、表格、引用、列表和标题样式。章节来源与电子书来源合并为正文末尾的“内容来源”折叠区，仍完整展示已有数据。上下章按钮显示方向、章节名及边界状态；切换章节时只更新正文区域并保持错误重试能力。

点赞与收藏使用可见文字与图标，不依赖颜色表达状态。未登录用户操作时继续跳转登录并带回原阅读地址。阅读量记录、章节 query 深链和 30 分钟去重规则保持不变。

### 5.4 我的收藏与个人资料

收藏页与个人资料共享“个人空间”页面标题和局部导航。收藏卡片沿用首页电子书卡片结构，额外显示收藏时间与取消收藏操作。取消收藏仍需即时反馈；当当前页最后一条被移除时，保持现有自动回退页码行为。

个人资料从单独的大卡片调整为清晰的账号摘要和信息列表，并根据角色提供相关快捷入口：注册用户前往收藏，管理员进入管理台。当前接口只支持查看资料，因此不伪造编辑能力。

### 5.5 登录与注册

认证页保留海洋背景和品牌叙事，但表单始终是首要视觉焦点。桌面端采用品牌侧栏加表单卡片，移动端隐藏大幅侧栏并保留简短品牌标题。

表单使用持续可见标签、必要的输入提示、就近校验和统一错误摘要。提交时锁定重复操作并显示加载状态。登录继续支持登录名或邮箱，注册规则、成功后返回登录、重定向安全校验均保持不变。

### 5.6 管理工作台概览

新增纯前端管理概览路由，复用现有统计接口，不要求后端变更。页面展示平台关键数字、趋势图以及分类、电子书、用户管理的快捷入口。若统计接口失败，管理入口仍然可用。

### 5.7 分类管理

分类管理采用分组列表而非将父子层级压成普通表格。每个一级分类显示其二级分类数量和对应子项，创建二级分类的入口与父级上下文绑定。编辑和删除仍使用现有接口与限制，规则说明放在相关操作附近。

移动端不显示横向滚动表格，改用卡片式列表。空状态直接提供“新增一级分类”。

### 5.8 电子书管理

页面结构固定为标题与主操作、筛选工具栏、结果摘要、数据表格或移动卡片、分页。状态筛选、分类筛选和关键词可单独清除，并提供统一重置。

桌面表格优先展示封面/标题、分类、状态、更新时间或发布时间和主要操作；低频操作收纳到更多菜单。草稿可编辑、上传封面、管理章节、发布和删除；已发布可阅读和撤回，现有发布完整性规则不变。

电子书创建与编辑继续使用模态框，但分为“基本信息、封面、来源与发布准备”三个可扫描区域。字段计数和发布所需条件在表单中提前提示。保留未保存内容离开保护与封面上传部分成功提示。

### 5.9 章节管理

顶部显示电子书上下文、发布状态、章节数以及返回入口。章节列表突出真实排序序号，搜索结果仍保留原章节序号。上下移动、编辑和删除动作按频率排序，移动端改用操作菜单。

章节编辑继续复用 Tiptap，但工具栏按文本、结构、媒体分组，按钮提供文本提示或可访问名称。标题、正文和来源说明形成清晰的编辑顺序。保留未保存修改确认、图片上传、富文本清洗和切章失败重试等现有行为。

### 5.10 用户管理

筛选工具栏、结果摘要、表格和分页与电子书管理保持同一模式。账号状态与角色使用文字标签和颜色双重表达。禁用、启用、重置密码和注销继续遵守总管理员与子管理员边界。

危险操作弹窗明确说明影响范围；注销继续表述为不可恢复，禁用则说明可以重新启用。移动端使用账号卡片，避免宽表强制横向滚动。

### 5.11 404 与错误体验

404 页面使用品牌化插图或简洁海洋图形，提供返回书库和返回上一页。页面级异常、区域级异常和表单级异常采用不同容器，避免所有错误都只通过短暂消息提示。错误文案说明发生了什么以及用户可以做什么。

## 6. 组件与代码边界

新增或抽取以下可独立理解的组件：

- `PublicShell`：公共导航、用户菜单和页脚。
- `AdminShell`：管理侧栏、移动抽屉、面包屑和内容容器。
- `ReaderShell`：紧凑阅读工具栏与阅读区域。
- `PageHeader`：页面标题、说明和主要操作。
- `FilterToolbar`：管理列表通用筛选布局。
- `StatePanel`：加载、空数据和区域错误状态。
- `EbookCard`：首页与收藏页共享的电子书呈现。
- `StatusTag`：电子书状态、账号状态和角色的统一语义标签。
- `StatCard` 与 `TrendChart`：统计摘要与趋势图拆分。

页面组件继续负责请求编排、分页和业务动作；展示组件通过明确 props 和事件与页面通信，不直接调用 API。API 模块、认证会话模块和后端契约保持不变。

全局 CSS 拆分为设计令牌、基础元素、布局和共享组件样式；页面特有样式优先使用组件 `scoped` 样式。避免继续扩大全局单文件样式表，也不引入新的 CSS 框架。

## 7. 数据流与状态

- 路由守卫继续刷新登录身份并执行访客、注册用户、管理员和总管理员边界。
- App 根据当前路由和身份选择布局；用户菜单由现有响应式会话状态驱动。
- 首页搜索、分类、分页共用单一查询状态，任一筛选变化将页码重置为 1；继续使用请求序号避免旧响应覆盖新结果。
- 阅读页并行加载电子书和章节目录；登录注册用户再加载互动状态。章节正文按需请求，URL query 始终反映当前章节。
- 管理列表页面维护独立筛选、分页和动作状态；刷新数据后校正超出范围的页码。
- 不引入全局状态库；当前应用规模使用 Vue 响应式模块与页面局部状态已经足够。

## 8. 错误与边界处理

- 首屏接口互不阻塞：统计失败不应阻止分类和电子书使用，反之亦然。
- 所有异步按钮防止重复提交，并在失败后恢复可操作状态。
- 图片缺失使用稳定比例的品牌占位，图片加载失败也回退到占位。
- 空分类、空电子书、空收藏、空章节、无搜索结果分别提供针对性说明。
- 认证过期继续清理会话并返回登录页；安全重定向只接受站内绝对路径。
- 已发布内容不可直接编辑或删除等后端规则，通过禁用状态与就近说明提前表达，但仍以后端校验为准。
- 移动端任何主要页面不得产生文档级横向滚动；确需宽内容的富文本表格在内容区内部滚动。

## 9. 测试与验收

保留现有 Playwright 流程，并根据新布局调整定位方式，继续验证：

- 注册用户登录、章节深链、点赞、收藏、上下章与刷新保持。
- 收藏列表可进入阅读页并取消收藏。
- 统计请求失败后能够局部重试恢复。
- 过期登录返回登录页，404 页面提供有效入口。
- 切章失败后能够重试目标章节。
- 管理端章节搜索保持真实序号，未保存编辑保护有效。

新增视觉与交互验收：

- 375、768、1024、1440 像素视口无文档级横向溢出。
- 桌面和移动导航均可使用键盘完成核心路径。
- 管理端侧栏、移动抽屉和阅读目录不会遮挡正文。
- 首页加载、错误、空数据、筛选中和有数据状态布局稳定。
- 所有图标按钮具有可访问名称，焦点指示清晰可见。
- `prefers-reduced-motion` 下无非必要持续动画。
- `npm run build` 与端到端测试通过，浏览器无未处理异常。

## 10. 实施范围与顺序

本次只重构前端，不修改后端接口、数据库结构、权限定义和业务规则，也不新增阅读进度、推荐算法、标签系统、资料编辑或实时通知。

实施顺序：

1. 建立设计令牌、共享组件与路由布局。
2. 重构公共导航、首页书库和电子书卡片。
3. 重构阅读页、收藏页、个人资料和认证页。
4. 建立管理工作台与管理概览。
5. 重构分类、电子书、章节和用户管理页面。
6. 调整统计图、响应式布局、无障碍细节和自动化测试。
7. 完成构建、端到端验证和桌面/移动视觉检查。

完成标准是：所有既有业务流程保持可用，全站形成统一的海洋主题设计系统，读者端更快进入内容，管理端更清晰地完成任务，并通过现有及新增验收项。
