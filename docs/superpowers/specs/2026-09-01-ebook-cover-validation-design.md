# 电子书封面校验修复设计

## 目标

修复电子书封面上传的真实图片校验，以及数据库更新失败时新封面文件的清理。保持现有接口、上传大小限制和 JPEG、PNG、WebP 支持不变。

## 方案

- 增加 `org.sejda.imageio:webp-imageio:0.1.6`，让 Java `ImageIO` 能解码 WebP。
- 封面文件先按 JPEG、PNG、WebP 签名识别目标格式，再统一以 `ImageIO.read` 解码。只有解码成功且宽高大于零时才保存文件；任何伪造或损坏内容均返回现有的无效图片业务错误。
- 保存新封面后、更新电子书数据库记录前，注册事务完成回调。事务提交后删除旧封面；事务回滚后删除新封面。旧文件删除失败只记录日志，不能回滚已提交的数据库记录。

## 测试

- 合法 JPEG、PNG、WebP 可上传。
- 伪造 PNG 签名、伪造 WebP 容器和普通非图片均被拒绝。
- 模拟 `EbookMapper.updateById` 失败并触发事务回滚后，验证新保存封面被清理。
- 运行 Maven 完整测试与前端生产构建。

## 范围外

- 不修改封面存储路径、上传接口、数据库表结构或前端交互。
- 不调整已完成的 V7 历史数据迁移。
