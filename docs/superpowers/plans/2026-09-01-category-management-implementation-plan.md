# 分类管理实施计划

1. 新增分类约束与演示数据 Flyway 迁移：用生成列统一一级/二级分类的唯一性范围，创建二级演示分类并迁移历史演示电子书。  
   验证：全新数据库迁移成功；演示电子书归属二级分类。

2. 新增 `category` 领域的实体、Mapper、请求/响应 DTO、Service 和 Controller。实现两级校验、自动同级排序、同级名称唯一、引用删除保护和管理员鉴权。  
   验证：MockMvc 覆盖公开树、管理员增改删、越权、重名、越级、改挂和被引用删除。

3. 新增前端分类 API、公开分类导航与管理员分类管理页面；扩展路由和导航入口。  
   验证：前端类型检查与生产构建通过；页面可展示加载、空状态、表单错误和无权限反馈。

4. 运行后端测试与前端构建，并使用本地 Docker MySQL/Redis 做一次 HTTP 冒烟测试。  
   验证：Maven 测试、`npm run build` 与关键接口请求均成功。
