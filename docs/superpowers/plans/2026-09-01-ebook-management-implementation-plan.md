# 电子书管理实现计划

1. 新增 Flyway `V6`：补充发布时间和演示数据兼容性，不修改已发布迁移。
2. 建立 `ebook` 领域模型、Mapper、DTO、服务与控制器；实现管理员鉴权、二级分类校验、分页搜索、草稿/发布状态与删除边界。
3. 实现封面服务：真实媒体类型、5 MB 限制、安全保存、替换顺序与草稿删除清理。
4. 编写集成测试：权限、公开隔离、分页搜索、发布完整性、封面边界、删除规则。
5. 增加前端 API、管理路由和电子书管理页；使用 Ant Design Vue 表格、表单、上传与确认反馈。
6. 重构前台首页电子书卡片/筛选/分页以调用公开接口，并保留现有海洋主题和响应式布局。
7. 执行 Maven 测试、前端生产构建和本地 Docker MySQL/Redis HTTP 联调；审查变更并拆分提交。
