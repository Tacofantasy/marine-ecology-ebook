# 实训验收清单

## 演示顺序（约 10 分钟）

| 步骤 | 操作 | 预期结果 |
| --- | --- | --- |
| 1 | 访客浏览分类、搜索、分页 | 只显示已发布内容，空结果有说明 |
| 2 | 总管理员创建两级分类 | 同级名称不可重复，不允许第三级 |
| 3 | 创建草稿、填写简介和来源、上传封面 | 草稿不公开；清空可选字段后重新打开仍为空 |
| 4 | 添加两篇图文章节，插入链接与正文图片 | 保存后内容一致；空正文无法保存 |
| 5 | 搜索第二章，再清空搜索调序 | 原目录序号保留，搜索时禁用排序；完整目录可排序 |
| 6 | 修改表单后关闭或导航离开 | 提示是否放弃，继续编辑时保留内容 |
| 7 | 发布电子书 | 不完整内容拒绝发布，完整内容显示在书库 |
| 8 | 访客切换章节并刷新 | 地址保存当前章节，目录与正文一致，来源可见 |
| 9 | 注册读者、登录、点赞、收藏 | 状态持久化，可取消；我的收藏可继续阅读 |
| 10 | 查看统计，模拟请求失败再重试 | 今日卡片与趋势口径一致，图表能恢复 |
| 11 | 撤回电子书并重新发布 | 撤回后不可阅读，收藏暂不可见；发布后恢复 |
| 12 | 创建子管理员、禁用读者、重置密码 | 角色边界有效；禁用或重置使旧会话失效 |

## 交付检查

- 在接收电脑启动，首页、管理页、阅读页刷新均可访问。
- 登录、分类接口、封面及正文图片上传回显正常。
- 重启后电子书、章节、图片、点赞收藏仍然存在。
- 源码、lockfile、Flyway 迁移、测试记录、需求和设计文档一并交接。
- 真实 .env 不进 Git；账号信息、数据库备份和上传目录单独交接。
- 准备至少一本有完整来源说明的正式展示电子书，不以测试正文替代。

## 统计口径与边界

阅读量按章节打开计数。同一账号或访客 IP，在同一章节的 30 分钟内只计一次。今日阅读来自 Redis 自然日计数；今日点赞统计当天创建且仍保留的点赞，取消后会减少。

“在库累计”按当前仍存在的电子书和点赞记录汇总；删除内容后会减少。今日阅读保留当天已发生的阅读，因此在删除内容的当天可能高于在库累计阅读。

今日趋势直接取实时计数；历史趋势取 MySQL 快照，无记录日期补零。每小时保存当天采样，每日 00:05 结算昨日，已结算历史冻结。快照累计值是实际采样时的业务表值，不能精确还原历史某一秒的状态。

长时间停机、Redis 数据丢失或错过结算时，完整历史不能凭空回补。预计阅读时长按约 400 字/分钟估算。容器统一使用 Asia/Shanghai；本机 Java 与数据库也应使用一致时区。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 首次书库为空 | 初始数据是草稿，管理员补齐内容后发布 |
| 登录连接失败 | 检查 API 日志、MySQL、Redis；开发模式检查 Vite 代理 |
| 容器提示缺少变量 | 对照 .env.example 补齐已有 .env，尤其管理员凭据 |
| 回到登录页 | 会话过期、被禁用或密码重置，重新登录 |
| 上传失败 | 仅 JPEG/PNG/WebP，最多 5 MB；检查上传目录写权限 |
| 搬迁后图片丢失 | 检查 UPLOAD_ROOT 和原上传目录是否一起迁移 |
| Flyway 迁移失败 | 保留日志并备份排查，不修改已执行的历史迁移 |
| Docker Hub 返回 EOF | 恢复仓库网络后重建，或使用单 JAR 交付 |

## 备份与恢复

备份时暂停内容编辑，保存 MySQL 逻辑备份（可使用 mysqldump --single-transaction）和完整上传目录。恢复时停止应用、导入数据库、还原上传文件，再启动验证正文与图片。完整迁移近期统计时还需迁移 Redis 数据；容器 Redis 已启用 AOF。

开发、完整容器和测试环境使用独立数据存储。日常停止不要执行删除持久卷的 down -v。测试 MySQL 使用临时存储，不能承载正式内容。
